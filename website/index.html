THE ART OF READING / CHAPTER 01

从问题开始

阅读之前，先写下你希望理解的问题。问题不必复杂，它可以是一个概念、一种方法，或者一个结论成立的条件。明确问题，可以帮助你选择阅读的顺序。

对于一本书，目录提供了作者安排内容的方式。先看章标题，再看章节之间的关系。不要把目录当作内容本身。标题能告诉你主题，却不能替代论证。

对于一篇论文，可以先读摘要、引言与结论。记录作者声称解决的问题，再到方法和实验中核对证据。阅读顺序可以改变，但对证据的要求应当保持一致。

第一次阅读不需要理解每一个细节。把暂时不明白的术语标记下来，同时记录它出现的位置。

Local-first

你的书库，
只留在你的电脑上。

原始文件存放在文件系统，进度、批注、对话与设置存放在 SQLite。没有内置云同步。

  • 只监听本机回环地址Go 服务绑定 127.0.0.1 的随机端口，每次启动生成新令牌，应用关闭即停止。
  • 文档内容按不可信处理EPUB 导入时检查压缩包大小与资源路径，并在渲染前移除活动内容。
  • 由你决定 AI 看到什么只发送所选片段、当前章节或页面与近期对话；经由官方 CLI，在临时空目录中运行。

Get started

三步，开始第一页。

下载安装包，或使用 Node.js 22+、pnpm 10 与 Go 1.26 从源码运行。

1

安装

Apple Silicon 的 DMG 没有开发者签名，首次打开需在“系统设置 › 隐私与安全性”中允许。

# or from source git clone https://github.com/cynicalight/reader.git cd reader && pnpm install pnpm desktop
2

登录一个 CLI（可选）

阅读、搜索与笔记都不需要 AI。想用 AI 助读时，用官方 CLI 登录即可。

claude auth login # or codex login
3

打开一本书

拖入 EPUB / PDF，或按 ⌘O 导入。空书库里可以先体验示例文档。

⌘ O 导入文档 ⌘ K 快速查找
FAQ

常见问题

需要填写 API Key 吗？

不需要。Reader 调用你已登录的官方 Claude Code、Codex 或 Kimi CLI；权限、额度、模型与计费都跟随该 CLI 账户。

我的文档会被上传吗？

文档本身留在本机。使用 AI 时，所选片段或当前章节 / 页面以及近期对话会经由 CLI 发送；启用已验证识图能力的 Agent 后，PDF 中裁剪出的图表与公式会被发送去生成文字稿。

支持哪些平台？

安装包面向 Apple Silicon Mac。其他平台可以从源码运行，暂不提供 Linux 安装包。

扫描版 PDF 可以用吗？

暂未实现 OCR，扫描页会被明确标注为文本不完整。目前主要面向带文本的 PDF 与无 DRM 的流式 EPUB。

第一次打开 PDF 为什么要等一会儿？

首次分析会下载并校验约 67 MB 的版面模型，之后缓存在本地。不需要安装 Python 或 PaddlePaddle，重启后会继续处理。
