# PDF 翻译与对照阅读

## 已确认的交互

- 仅改变中间阅读区域，提供仅原文、原文译文、仅译文。双栏支持交换左右。
- 原文保留 PDF.js 渲染、划词、笔记及高亮。文字 block hover：右上角询问 AI，右下角整段翻译。
- 译文按连续单栏排版，保留标题、段落、图表、公式和阅读顺序。双栏和仅译文共用译文。
- 沉淀阶段翻译全文，逐段开放并本地保存；未完成段落显示状态，失败部分独立重试。
- 仅原文点击段落翻译打开附近的浮层，提供进入双栏入口；未完成段落提升优先级。
- 翻译摘要、标题、正文、图注、表注、脚注和可提取的表格文字。公式、代码、原图和参考文献条目保留。扫描页明确提示 OCR 限制。
- 双向划词采用句子级对应；跨句对应多个句子；缺少可靠映射时退回段落。关联高亮临时显示，与持久笔记区分。
- 默认双向同步滚动，可关闭；滚动按段落和阅读顺序定位，不按全文滚动百分比映射。程序滚动不能触发反向同步。
- 进入原文译文默认适合当前文字栏，按可用宽度计算缩放，避免固定 200%。本地文字坐标可在 AI 解析前用于分栏。
- 栏尾向下进入下一栏顶部，栏首向上进入上一栏底部；跨页保持阅读顺序，阻止同一次惯性连续换栏。
- 允许自由缩放和横向移动，此后暂停自动换栏；浮现适合单栏按钮，按当前阅读位置恢复。

## 实现边界

- 原始 PDF、既有笔记及图表解析稿不覆盖。译文必须等待 provider 明确完成并通过结构校验后保存。
- 翻译内容作为不可信资料，只用于生成内容，不授予执行工具的权限。
- 翻译缓存与原文版本绑定，句子覆盖必须完整且保持顺序；不可靠映射不得伪装为精确对应。
- 分栏需要兼容跨栏标题和图表；低置信度回退到整页。PDF.js 是原文渲染与文字选择的唯一引擎。
- 译文侧标注保留其语言和文字范围，同时关联到原文位置，不能把译文引用误当作原文搜索词。
- 自动跟随尊重手动缩放；主动侧控制同步，模式切换和 resize 尽量保持阅读位置。

## 参考

本地 `../easyread`，核对版本 `c33a151100eb102fb5f9562aa0ccb749a9ff9902`：

- `easyread/web/js/reader/pageview.js`：段落跟随、输入控制权和程序滚动抑制。
- `easyread/web/js/reader/sentences.js`：句子范围校验、失效时退回整段。
- `easyread/pdfwork.py`：段落与多个页面区域关联。

EasyRead 的原页面板采用图片；Reader 保留 PDF.js 的真实文字选区。参考其机制，不直接替换现有渲染器。

## 验证

重点覆盖翻译中断恢复、失败重试、来源变更、句子范围、同步回环、分栏阅读顺序及惯性边界。
完成 `pnpm typecheck`、`pnpm test`、`pnpm build`。不使用浏览器自动化进行视觉验收；用真实双栏和混排论文手动检查。
