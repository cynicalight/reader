# 从本机 Zotero 迁移

入口：论文库 → 导入论文 → 从 Zotero 导入。

1. 在 Zotero「设置 → 高级 → 资料目录」确认目录位置。默认使用用户主目录下的 `Zotero`；自定义资料目录可手动填写，桌面版也可以选择目录。目录需要同时包含 `zotero.sqlite` 和附件 `storage`。
2. 如果采用按需下载，先在 Zotero 中下载需要的 PDF。相对链接附件需要另外填写 Zotero 的链接附件基目录；绝对链接附件直接按本机路径读取。
3. 点击「扫描资料库」，查看可导入和需处理的条目。勾选需要的 PDF 后导入；一个 Zotero 条目有多个 PDF 时，每个附件分别成为 Reader 文档，共用条目信息。
4. 导入过程中可以停止后续附件；当前附件事务完成后停止。结果区区分新增、合并、已迁移和失败，可以导出 JSON 报告。补齐文件后重新扫描、重试。

## 迁移内容

- 本地 PDF 原文件，按字节复制。沿用论文库 50 MB、150 页限制；预览中明确说明 51–150 页的 PDF 也会进入论文库。
- 标题、作者（含团体作者）、文献类型、日期、出处、卷期页、出版者、DOI、arXiv、ISBN、URL、摘要、语言、Extra 备注等对应字段。Zotero 日期的排序前缀中的未知月、日转换为 Reader 可表示的精度；无法转换的原值留在迁移记录中，并在报告中说明。
- 条目的标签和所属分类层级。分类名称中的字面 `/` 转为全角 `／`，避免误识别为下级分类。超过 Reader 的 30 个标签/分类、40 字符限制时，报告列出无法转换的值，原值保留在迁移记录中。
- 子笔记及附件笔记追加到论文笔记，已有 Reader 笔记保留。HTML 转为纯文本，保留段落边界，移除脚本、样式和活动内容。富文本格式、嵌入图片和引用链接不转换。合并后超过 100000 字时，该附件整条失败，不截断。
- 高亮、下划线和便笺批注，包含摘录、评论、颜色、标签和原始创建时间。按 PDF 页码、裁剪框和页面旋转转换坐标。图片、手绘、文本框、跨页或无法定位的批注转入论文笔记，保留文本和原始位置，报告明确提示；图片及手绘视觉效果不迁移。

这是单向导入，不是持续同步。没有 PDF 的元数据条目、独立笔记、独立附件、网页快照和其他附件不导入；空分类、智能分类、条目关联、标签颜色、Zotero 阅读状态和文字处理器引用关系不迁移。无法导入的论文记录和独立条目计数会出现在预览或报告中。群组中已在本机的论文可读取，但不会复现群组权限或协作关系；不同库的同名分类会归到 Reader 同一分类。

## 数据保护和重试

Zotero SQLite 使用 `mode=ro`、`query_only` 和一致读事务，包含已提交 WAL 数据；扫描完成后关闭源数据库，不复制裸 SQLite 文件，也不向 Zotero 写入。预览快照保留一小时，继续导入会延长有效期；最多保留三次扫描。扫描期间避免整理或同步源库，文件在扫描后改变会要求重新扫描。仅适配 Zotero 6+ 的标准数据库表结构，未来的结构变化可能需要适配；不能读取时会明确失败。

Reader 按文件内容去重，Zotero 附件身份和文档 ID 共同记录迁移状态。已完成迁移的同一附件再次导入会跳过，不覆盖后续编辑或重新添加已删除的批注。相同 PDF 已由其他渠道导入时，保留既有标题和非空元数据，补齐空字段，合并标签、分类和未迁移笔记；已有手动空值也保留。回收站中的相同文件要求先恢复；已在图书库中的文件保留原库位置。迁入的元数据按手动值保护，自动查找不覆盖。

每个附件的文档、元数据、笔记、批注、迁移记录在同一个 Reader 数据库事务中提交。源文件复制到临时文件，校验后移动到 Reader 自有目录；正常事务失败清理该次创建的文件。突然断电造成未登记的目标文件时会报错，避免覆盖。一个附件失败不阻断其他附件。迁移不自动启动整库 AI 解析或翻译，阅读时可按需开启。

`zotero_imports` 保存成功导入附件的原始字段、作者、分类、标签、笔记 HTML 和批注位置快照；`zotero_note_imports` 记录逐笔记去重信息。这些是 Reader 内部迁移记录，随文档彻底删除而删除；目前没有单独的快照导出界面。JSON 报告包含每条记录的结果和警告，不是 Zotero 完整备份。

## 验证

自动测试使用构造的 SQLite 资料库与 PDF，不依赖私人 Zotero 数据，覆盖只读扫描、WAL 可见性、父子条目和删除过滤、链接附件、目录越界、扫描后文件变化、按哈希去重、事务回滚、元数据与已编辑笔记保护、重试、批注坐标与降级、预览有效期、HTTP 契约及界面部分失败/停止/报告流程。

手动验收：

1. 使用包含中文、嵌套分类、多个 PDF、一个缺失附件、一个链接附件、笔记和高亮的测试资料库。先扫描，确认尚未出现新文档；再勾选两篇导入，核对分类、标签、作者和 PDF 内容。
2. 打开 PDF，逐页检查高亮、下划线和便笺，特别检查旋转页和裁剪页；核对论文笔记中的降级批注与报告。
3. 修改 Reader 标题、笔记或批注后重新扫描导入，确认没有重复记录或覆盖修改。导出报告核对缺失附件和未选择条目。
4. 开始导入多个附件后点击停止，确认当前附件结束后停止，其余条目标为未导入；重新扫描能够继续。
5. 在浅色、深色、小窗口中检查对话框、长标题截断、滚动和键盘操作。桌面版额外检查两个目录选择按钮。

参考：[Zotero SQLite 只读访问](https://www.zotero.org/support/dev/client_coding/direct_sqlite_database_access)、[资料目录](https://www.zotero.org/support/zotero_data)、[批注存储](https://www.zotero.org/support/kb/annotations_in_database)。表结构与类型映射依据 Zotero 公布的格式独立实现。
